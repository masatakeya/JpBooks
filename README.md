# JpBooks — 日本語書籍検索・読書ノート生成プラグイン

書名・著者名から日本語書籍を検索し、書誌情報を流し込んだ読書ノートを作成するObsidianプラグインです。
Googleブックスではカバーしきれない絶版本・専門書・古い書籍を扱えるよう、国立国会図書館サーチを検索の起点にしています。

## データソース

| 役割 | サービス | エンドポイント | 認証 |
|------|----------|----------------|------|
| 検索（書名・著者名） | 国立国会図書館サーチ SRU API | `https://ndlsearch.ndl.go.jp/api/sru` | 不要 |
| 内容紹介の補完 | openBD | `https://api.openbd.jp/v1/get` | 不要 |

- NDLサーチから **書名・著者・出版社・出版年・ISBN** を取得します。レスポンスはSRU/XMLのため `DOMParser` で解析しています。
- 選択した書籍のISBNでopenBDに問い合わせ、**内容紹介（あらすじ）** を補完します。
- **ISBNが取得できない書籍や、openBDに内容紹介がない書籍でも処理は止まりません**。内容紹介は空欄のままノートが作成されます。
- 書影（カバー画像）は取得しません。APIキーの設定も不要です。

### API利用上の注意

- NDLサーチは同時リクエスト数に制限があり、大量アクセスは遮断される場合があります（具体的な数値は非公開）。本プラグインは1回の操作につき検索1リクエスト・内容紹介1リクエストのみを送り、検索中は追加のリクエストを受け付けません。
- 旧エンドポイント `iss.ndl.go.jp` は現行の `ndlsearch.ndl.go.jp` へリダイレクトされます。本プラグインは現行エンドポイントを直接呼びます。
- openBDに公開されたレート制限はありませんが、同様に1件ずつ問い合わせます。

## 使い方

1. リボンの本アイコン、またはコマンドパレットから **「JpBooks: 書籍を検索して読書ノートを作成」** を実行
2. 書名・著者名を入力して検索（どちらか一方だけでも可、Enterで検索）
3. 候補一覧から1件選択（↑↓キーで移動、Enterで決定）
4. 内容紹介を補完したうえで、テンプレートに沿ったノートが作成されます

## 設定

| 項目 | 内容 |
|------|------|
| 保存先フォルダ | ノートの作成先。存在しない場合は階層ごと自動作成します |
| ファイル名フォーマット | 既定は `{{title}}`。同名ファイルがある場合は連番を付けます |
| 検索結果の最大件数 | 1〜50件（既定20件） |
| 図書のみを検索 | `mediatype=books` で雑誌記事・電子資料等を除外（既定オン） |
| 内容紹介を取得する | openBDへの問い合わせのオン／オフ |
| 作成後にノートを開く | 作成したノートを開くかどうか |
| テンプレート | `{{変数名}}` 形式でカスタマイズ |

### テンプレート変数

| 変数 | 内容 |
|------|------|
| `{{title}}` | 書名（巻次を含む） |
| `{{author}}` | 著者名（カンマ区切り） |
| `{{authors}}` | 著者名（`{{author}}` と同じ文字列表現） |
| `{{publisher}}` | 出版社 |
| `{{published}}` | 出版年（`YYYY` / `YYYY-MM` / `YYYY-MM-DD`） |
| `{{year}}` | 出版年（`YYYY`） |
| `{{isbn}}` | ISBN-13（ハイフンなし） |
| `{{description}}` | 内容紹介 |
| `{{DATE}}` | ノート作成日（`YYYY-MM-DD`） |
| `{{DATE:YYYYMMDD}}` | ノート作成日（書式指定） |

frontmatter（先頭の `---` で囲まれた範囲）に挿入される値は、改行やダブルクォートを含んでいてもYAMLが壊れないよう自動でエスケープされます。
内容紹介を本文側に置きたい場合は、テンプレートの `description:` 行を削除し、本文に `{{description}}` を書いてください。

### 既定のテンプレート

```markdown
---
title: "{{title}}"
author: "{{author}}"
publisher: "{{publisher}}"
published: "{{published}}"
isbn: "{{isbn}}"
description: "{{description}}"
read_date:
rating:
tags:
  - 読書ノート
created: {{DATE}}
---

## メモ

```

`read_date`（読了日）と `rating`（評価）は自動取得の対象外です。空欄で用意されるので手動で埋めてください。

## 開発

```bash
npm install
npm run dev    # 変更を監視してビルド
npm run build  # 型チェック + 本番ビルド
```

ビルド生成物は `main.js` です。Vaultで使うには `main.js` / `manifest.json` / `styles.css` を
`<Vault>/.obsidian/plugins/jpbooks/` にコピーし、設定画面でプラグインを有効化してください。

### 構成

```
src/
  main.ts            プラグイン本体（コマンド・リボン登録）
  settings.ts        設定項目と設定画面
  note.ts            テンプレート展開とノート作成
  isbn.ts            ISBNの正規化・ISBN-10→13変換
  types.ts           書誌情報の型
  api/ndl.ts         NDLサーチ SRU クライアントとXML解析
  api/openbd.ts      openBDクライアント（内容紹介の取得）
  ui/SearchModal.ts  検索・候補選択モーダル
```

## スコープ外

- 書影（カバー画像）の取得・埋め込み
- ISBN入力・バーコードスキャンによる検索（書名・著者名検索のみ）
- 楽天ブックスAPIなど価格情報系データソース
- 他プラグイン・スキルとの連携
